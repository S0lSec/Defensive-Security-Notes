# Containment
- Prevent spread of the incident
- Divided into short-term and long-term containment
- All containment actions must be coordinated and executed across all systems simultaneously
- **Short-Term Containment**
	- Leaves minimal footprint
	- Contain damage
	- Provide time to develop more concrete remediation strategies
	- Have the opportunity to take forensic images and preserve evidence if not already done (known as the backup substage)
	- If shutting down a system is required get permission
- **Long-Term Containment**
	- Focus on persistent action and changes
	- Keep stakeholders updated
# Eradication
- Eliminate both root cause and whats left
- Rebuilding systems
- Restoring from backups
# Recovery
- Bring systems back to normal operation
- All restored systems will be subject to heavy logging and monitoring
- Compromised systems tend to be targeted again if the adversary regains access to the environment
