# Definition & Scope
- An **event** is an action occurring in a system or network
	- Sending an email
	- Mouse click
	- Firewall allowing connection
- An **incident** is an event with negative consequence
	- Incident can occur due to natural disasters

**Incident Handling** is a clearly defined set of procedures for managing and responding to security incidents in a computer or network environment.

Incident handling has two main activities
- **Investigating**
- **Recovering**

![[Pasted image 20260401224252.png]]

Incident response team/incident handling team respond to incidents to minimize or stop the theft of data or disruption of services. This is achieved by performing investigations and remediation steps.

Assist organizations in mitigating the risk from computer security incidents - https://nvlpubs.nist.gov/nistpubs/SpecialPublications/NIST.SP.800-61r3.pdf

- Always have resources in the first two stages
- Go step by step, for example don't contain 5 infected machines then write a report if there are still another 5 infected machines operating
# Investigating
- Discover the initial patient zero victim and create an ongoing (if still active) incident timeline
- Determine which tools and malware the adversary used
- Document the compromised systems and what the adversary has done
# Recovery
- Create and implement a recovery plan
- Once the plan is implemented the business should resume normal operations

# Different Types of Real-World Incidents
- Leaked Credentials
- Default/Weak Credentials
- Outdated Software/Unlatched Systems
- Rouge Employee/Insider Thread
- Phishing/Social Engineering
- Supply-Chain Attack
