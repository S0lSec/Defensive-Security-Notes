Defence is depth is about adding multiple layers to reduce risk and mitigate threats.
## Assets, Vulnerabilities & Threats
**Asset** - Anything of value to an organisation that must be protected
**Vulnerability** - A weakness in a system or its design that could be exploited by a threat actor
**Threat** - Any potential danger to an asset

### Example:
Having a server that stores very important data (homework ;D). Then adding passwords to the server so only authorised people can access it. But then you add a network firewall to prevent anyone from being able to crack that password. Then adding a host firewall to prevent any malware from damaging the data. Then adding a SIEM and hiring an analyst to monitor the network traffic to ensure no suspicious traffic is reaching the server. But thats not enough so you add an IPS to even further prevent suspicious traffic. etc,etc,etc.
